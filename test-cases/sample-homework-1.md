# Test Case: การบ้านคณิตศาสตร์ — การแยกตัวประกอบ

ไฟล์นี้เป็นชุดทดสอบสำหรับฟีเจอร์ตรวจการบ้าน (`app/api/analyze-homework/route.ts`)
ประกอบด้วย 3 ส่วน: (1) สิ่งที่นักเรียนเขียน (จำลองภาพถ่ายลายมือ) (2) เฉลย/เกณฑ์การให้คะแนน
ที่ใช้กรอกในช่อง `answerKeyText` (3) คะแนน/ผลลัพธ์ที่คาดว่า AI ควรให้ เพื่อใช้เทียบผลจริง

---

## 1. สิ่งที่นักเรียนเขียน (mock ของภาพถ่ายลายมือ)

> ใช้ข้อความนี้แทนภาพถ่ายลายมือนักเรียน (ถ่ายภาพ/พิมพ์ข้อความนี้ลงกระดาษเพื่อทดสอบจริงกับ
> endpoint ที่รับภาพ), ชื่อ: ณัฐวุฒิ สินธุ์เจริญ, วิชา: คณิตศาสตร์ ม.2, หัวข้อ: การแยกตัวประกอบ

```
ข้อ 1) x^2 + 5x + 6
= (x + 2)(x + 3)

ข้อ 2) x^2 - 9
= (x - 3)(x + 3)

ข้อ 3) 2x^2 + 8x
= 2x(x + 4)

ข้อ 4) x^2 - 6x + 9
= (x - 3)(x - 3)
```

*หมายเหตุ: ข้อ 4 นักเรียนไม่ได้เขียนสรุปเป็น (x - 3)^2 ทำให้ดูไม่ครบขั้นตอนสุดท้าย*

---

## 2. เฉลย / เกณฑ์การให้คะแนน (สำหรับกรอกในช่อง `answerKeyText`)

```
เฉลย:
1) x^2 + 5x + 6 = (x + 2)(x + 3)
2) x^2 - 9 = (x - 3)(x + 3)
3) 2x^2 + 8x = 2x(x + 4)
4) x^2 - 6x + 9 = (x - 3)^2

เกณฑ์การให้คะแนน (รวม 100 คะแนน แบ่งข้อละ 25 คะแนน):
- คำตอบถูกต้องครบทุกขั้นตอน = ได้เต็มข้อ (25 คะแนน)
- คำตอบถูกต้องแต่ไม่สรุปรูปแบบมาตรฐาน (เช่น ไม่เขียนเป็นกำลังสอง) = หัก 5 คะแนน
- วิธีทำถูกแต่คำนวณผิดจุดเดียว = หัก 10 คะแนน
- วิธีทำผิดตั้งแต่ต้น = ได้ 0 คะแนนในข้อนั้น
```

## 3. ผลลัพธ์ที่คาดหวัง (expected output, ไว้เทียบกับ JSON ที่ AI ตอบกลับ)

| ข้อ | คำตอบนักเรียน | ถูก/ผิด | คะแนนที่ควรได้ |
|---|---|---|---|
| 1 | (x + 2)(x + 3) | ถูกต้องครบถ้วน | 25/25 |
| 2 | (x - 3)(x + 3) | ถูกต้องครบถ้วน | 25/25 |
| 3 | 2x(x + 4) | ถูกต้องครบถ้วน | 25/25 |
| 4 | (x - 3)(x - 3) | ถูกแต่ไม่สรุปเป็นกำลังสอง | 20/25 |

**คะแนนรวมที่คาดหวัง:** `score` ≈ `95`

**strengths ที่คาดว่า AI ควรพูดถึง:**
- แยกตัวประกอบได้ถูกต้องทั้ง 4 ข้อ
- เข้าใจวิธีดึงตัวร่วม (common factor) ในข้อ 3

**weaknesses ที่คาดว่า AI ควรพูดถึง:**
- ข้อ 4 ไม่ได้เขียนคำตอบสุดท้ายในรูปกำลังสองสมบูรณ์ (x - 3)^2

**suggestions ที่คาดว่า AI ควรพูดถึง:**
- แนะนำให้ฝึกสังเกตรูปแบบ a^2 - 2ab + b^2 เพื่อสรุปเป็นกำลังสองได้เร็วขึ้น

3. กดตรวจ แล้วเทียบผลลัพธ์ (`score`, `strengths`, `weaknesses`, `suggestions`) กับส่วนที่ 3
